# 「마지막 등불」 게임 디자인 요약

해가 뜨지 않게 된 지 백 년. 마지막 등불지기가 꺼져가는 등불 하나를 들고 살아 있는 밤을 버틴다.
반전: 밤의 정체는 지쳐서 스스로를 삼킨 옛 태양이고, 등불의 불씨는 그 태양의 마지막 조각이다.

수치는 `src/game/config.ts`(몬스터·보스·빛), `src/game/data/`(무기·패시브)에서 조정한다.

## 화면과 색
| 요소 | 디자인 |
|---|---|
| 바닥 | 짙은 남색 바탕에 보랏빛 얼룩, 말라 죽은 풀, 돌, 갈라진 땅 |
| 어둠 | 화면 전체를 어둠 막이 덮고 등불 주변만 둥글게 밝음 (기본 반경 170) |
| 공격 이펙트 | 따뜻한 주황·금색, 빛이 더해지는(ADD) 효과 |
| 경험치 | 금빛 불씨. 어둠 속에서도 보임 |
| 그래픽 | 지금은 코드로 그린 임시 그림 (`src/game/art/Textures.ts`). 같은 이름으로 이미지를 로드하면 교체됨 |

## 무한 스크롤 배경
- 512px 배경 이미지 9장(3x3)만 만들고, 플레이어가 칸을 넘어가면 그 이미지들을 새 위치로 옮겨 재사용한다.
- 칸 좌표로 무늬를 정하므로 같은 곳에 돌아오면 같은 바닥이 보인다.
- 너무 멀어진 짐승은 화면 가장자리로 다시 데려오고, 2500px 넘게 남겨진 불씨는 정리한다.

## 등불지기와 무기
| 무기 | 동작 | 최대 레벨(5) |
|---|---|---|
| 등불의 온기 | 빛이 닿는 적에게 1초마다 작은 피해, 레벨업 시 빛 반경 증가 | 데미지 16, 반경 +60 |
| 불씨 탄 (시작 무기) | 손에 든 등불에서 가장 가까운 적에게 불덩이 발사 | 3발, 데미지 20 |
| 불씨 웅덩이 | 주변 랜덤 위치에 원형 장판, 0.25초 뒤 안의 적에게 피해 | 장판 4개, 데미지 40 |

패시브 4종(신발, 심장, 힘, 시계)은 그대로 유지한다.

## 몬스터
| 이름 | 특징 |
|---|---|
| 그을린 짐승 - 들개 | 체력 30→45, 속도 85. 빛 밖에서는 주황빛 두 눈만 보이고, 빛 안에서 검은 연기 형체가 드러남 |
| 그을린 짐승 - 늑대 | 체력 40→55, 속도 100. 비율이 15%에서 1분마다 6%씩 늘어 최대 60% |
| (짐승 공통) 체력 증가 | 게임 시작 때 최솟값에서 10분까지 최댓값으로 서서히 증가 (생성 순간 기준, `BEASTS.hpMin/hpMax`) |
| (짐승 공통) 초반 완화 | 1분 30초까지 이동 속도 -5%, 생성 간격 1.2초 고정 (`EARLY_GAME`) |
| (짐승 공통) 생성 간격 | 1분 30초까지 1.2초 → 3분 0.9초 → 5분 0.15초(초당 약 6~7마리)로 서서히 감소, 이후 유지 (`SPAWN.intervalKeyframes`) |
| 밀랍 순례자 (중간 보스) | 체력 800, 느림(60). 2.5초마다 심지에서 밀랍 탄 3발, 맞으면 2초간 45% 둔화. 2분 30초마다 등장 |
| 재의 나방 여왕 (후원 전용) | 재 가루로 4초간 빛 반경 55%로 축소, 6초마다 경로를 예고한 뒤 일직선 돌진. 처치 시 불씨 30개. 후원 2만 원마다 체력 +100%(최대 4배), 4만 원마다 피해 +100%(최대 2.5배) |

## 최종 보스: 긴 밤 (일식)
10분에 등장. 화면 위쪽 하늘에 떠 있고 땅에 내려오지 않는다. 체력 15000.

| 페이즈 | 조건 | 패턴 |
|---|---|---|
| 1 | 등장 시 | 어둠이 짙어지고(0.8→0.93) 다른 몬스터 전부 사라짐. 5초마다 부채꼴 장판(25), 1초마다 화면 가장자리에서 밀랍 탄 1~3발(둔화), 20초마다 플레이어 위치에 운석 5연타(0.2초 간격) |
| 2 | 체력 66% 이하 | 1페이즈 반복 + 15초마다 중간 보스 패턴을 번갈아 시전 (밀랍 탄막 9발 / 재 가루 + 그림자 나방 돌진) |
| 3 | 체력 33% 이하 | 일식이 갈라지며 꺼져가는 옛 태양의 얼굴이 드러남. 1, 2페이즈 패턴 중단. 5초마다 어둠의 손아귀, 10초마다 맵 전체 공격(피할 수 없음, 맞으면 0.2초 멈춤). 체력이 줄수록 태양이 밝아지고 어둠이 걷힘(0.93→0.3) |
| 엔딩 | 처치 | 화면 전체가 새벽빛으로 하얗게 덮이며 "새벽" |

## 소리 (src/game/audio)
음원 파일 없이 Web Audio 로 실시간 합성 (저작권 문제 없음, 용량 0)
- 메인 BGM 「마지막 등불」 (Music.ts): D 단조 84 BPM, 오르골 아르페지오 + 플루트 멜로디 + 패드 + 심장 박동 북. 도입 4마디 -> A -> B -> A -> B 반복 (약 1분 40초)
- 효과음 (Sound.ts): 불씨 탄 "슉", 등불의 온기 "우웅", 불씨 웅덩이 생성 "스으" / 폭발 "화르륵 쿵", 짐승 피격 "툭", 보스 피격 "쾅", 처치 "푸스스"
- 같은 소리가 한 프레임에 겹치면 최소 간격으로 걸러냄. M 키로 소리 켜기/끄기 (브라우저에 저장)
- 새 효과음 추가: Sound.ts 의 SfxName, MIN_GAP, SFX 에 하나씩 추가하고 sound.play('이름') 호출

## 테스트 버튼 (화면 오른쪽 아래)
밀랍 순례자 소환 / 나방 여왕(후원 5천원, 5만원) / 긴 밤 소환 / 긴 밤 다음 페이즈

## 후원 연동
방송 후원(치지직 / Discord)은 StreamDirector AI 서버가 받아서 판단하고, `spawn_boss` 이벤트를 보내면 `systems/AudienceEvents.ts` 가 `Game.onDonation(금액, 후원자)`를 호출해 나방 여왕을 소환한다. 자세한 규격은 `StreamDirector/docs/game_integration.md`.
