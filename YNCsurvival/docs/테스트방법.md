# 테스트 방법

게임과 채팅 서버를 로컬에서 켜고 확인하는 순서입니다. 모든 명령은 VS Code 터미널(PowerShell)에서 실행합니다.

## 0. 처음 한 번만 (새 PC에서)
```powershell
cd C:\Users\YNC\Desktop\AI\YNCsurvival
npm install

cd middleware
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env      # Discord 토큰을 넣으려면 .env 를 열어서 DISCORD_BOT_TOKEN= 뒤에 붙여넣기
```

## 1. 서버 두 개 켜기 (터미널 두 개)
VS Code 터미널 창 오른쪽 위 `+` 버튼으로 터미널을 하나 더 엽니다. 두 터미널 모두 테스트하는 동안 켜 둡니다.

**터미널 1: 채팅 서버 (채팅 테스트를 안 하면 생략 가능)**
```powershell
cd C:\Users\YNC\Desktop\AI\YNCsurvival\middleware
.\.venv\Scripts\python server.py
```
정상이면 이런 줄이 나옵니다.
```
INFO:     Uvicorn running on http://127.0.0.1:8000
[INFO] Discord 로그인 완료: ync#1087          ← .env 에 토큰이 있을 때
[INFO] 수신 채널: #테스트채팅 (1557...)
[INFO] 더미 채팅 철수: GG -> 게임 0개로 전송    ← DUMMY_CHAT=1 일 때
```

**터미널 2: 게임**
```powershell
cd C:\Users\YNC\Desktop\AI\YNCsurvival
npm run dev-nolog
```
정상이면 `Local: http://localhost:8080/` 이 나옵니다.

## 2. 브라우저에서 접속
http://localhost:8080 에 접속해서 화면을 클릭하면 시작됩니다.
- 채팅 서버가 켜져 있으면 왼쪽 아래에 `[시스템] 채팅 서버 연결됨`이 뜹니다.
- 이때 터미널 1의 로그가 `게임 1개로 전송`으로 바뀝니다. 0개면 게임과 서버가 연결되지 않은 것입니다.

## 3. 채팅 / 후원 테스트
**관리 화면 http://localhost:8000** 에서 출처(치지직 / Discord / 더미)를 켜고 끄거나, 채팅·후원을 직접 보낼 수 있습니다.
후원을 보내면 게임 채팅창에 `[후원]` 이 금색으로 뜨고 재의 나방 여왕이 소환됩니다. 치지직 연결 방법은 `middleware/README.md` 참고.

| 방법 | 하는 법 |
|---|---|
| 관리 화면 | 테스트 전송 칸에서 채팅 / 후원 보내기 |
| 더미 채팅 | 관리 화면에서 더미 ON (또는 `.env` 에 `DUMMY_CHAT=1`) → 1~3초마다 가짜 채팅 |
| 치지직 | 관리 화면에서 치지직 연결 후, 방송 채팅창에 입력하거나 후원 |
| 수동 전송 | 터미널을 하나 더 열고 아래 명령 실행 (또는 http://localhost:8000/docs → `POST /chat` → Try it out) |
| Discord | `.env` 의 `DISCORD_CHANNEL_IDS` 채널에 본인 계정으로 메시지 입력 |

```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8000/chat -ContentType 'application/json; charset=utf-8' -Body '{"user": "테스터", "text": "수동 채팅 테스트입니다"}'
```
결과가 `ok: True, clients: 1` 이면 게임 화면 왼쪽 아래에 메시지가 뜹니다.

## 4. 보스 테스트 (화면 오른쪽 아래 TEST 버튼)
| 버튼 | 확인할 것 |
|---|---|
| 밀랍 순례자 소환 | 2.5초마다 밀랍 탄 3발, 맞으면 등불지기가 누렇게 변하며 느려짐 |
| 나방 여왕 (후원 5천원 / 5만원) | 이름표에 후원 금액, 5만원 쪽이 체력이 더 많음. 재 가루로 빛이 좁아지고, 회색 경로 예고 후 돌진 |
| 긴 밤 소환 | 짐승이 모두 사라지고 어두워짐. 부채꼴 장판, 가장자리 밀랍 탄, 운석 |
| 긴 밤 다음 페이즈 | 2페이즈(밤이 더욱 짙어진다) → 3페이즈(옛 태양의 얼굴, 어둠의 손아귀, 화면 전체 공격) |

나방 여왕은 최대 2마리, 밀랍 순례자는 최대 3마리까지 소환됩니다. 긴 밤이 있는 동안에는 다른 보스를 소환할 수 없습니다.

## 5. 게임 내부 값 확인 (F12 콘솔)
`npm run dev-nolog` 로 띄운 개발 모드에서만 됩니다.
```js
game.scene.getScene('Game').stats                    // 이동 속도, 최대 HP 등
game.scene.getScene('Game').player.hp = 99999        // 죽지 않게 (오래 테스트할 때)
game.scene.getScene('Game').experience.gain(50)      // 경험치 50 → 레벨업 카드 테스트
game.scene.getScene('Game').onDonation(30000, '홍길동')  // 후원 3만원으로 나방 여왕 소환
```

## 자주 나오는 문제
| 증상 | 원인 / 해결 |
|---|---|
| 브라우저에 `ERR_CONNECTION_REFUSED` | 터미널 2(게임)가 꺼져 있음 |
| 채팅이 안 뜸, 서버 로그가 `게임 0개로 전송` | 게임 화면을 안 열었거나 채팅 서버를 게임보다 늦게 켬. 3초 안에 자동 재연결되니 잠시 기다리기 |
| `.env` 를 고쳤는데 반영이 안 됨 | 터미널 1을 `Ctrl+C` 로 끄고 다시 실행 |
| `address already in use` / `10048` | 같은 서버가 다른 터미널에서 이미 켜져 있음 |
| Discord 메시지가 안 뜸 | 터미널 1 로그 확인: `무시: ... 수신 채널이 아님`(다른 채널에 씀), `내용이 비어 있음`(Message Content Intent 꺼짐) |
| 배포 주소에 최신 변경이 없음 | https://yncjin.github.io/AIProject/ 는 GitHub 에 push 한 버전만 반영됨 |
